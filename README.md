# Ambrosia Catering Landing Page

A modern and fully responsive catering company landing page built with **HTML5, CSS3, and Bootstrap 5.3**. The project focuses on clean UI, responsive layouts, semantic HTML, and accessible user interactions.

## ✨ Features

* Fully responsive design for desktop, tablet, and mobile devices
* Modern catering company landing page
* Responsive three-column feature layout
* Newsletter subscription form with email validation
* Responsive footer with social media links
* Semantic HTML5 structure
* Bootstrap 5 utility and responsive classes

## 🛠️ Technologies Used

* **HTML5** — Semantic page structure
* **CSS3** — Custom styling, variables, media queries, and responsive typography
* **Bootstrap 5.3** — Responsive grid and utility classes
* **Font Awesome 4.7** — Icons
* **Google Fonts (Nunito)** — Typography



## ♿ Accessibility

The project includes basic accessibility practices:

* Semantic HTML5 elements
* Proper form labels
* Keyboard-accessible interactive elements
* Visible focus states
* Responsive text and layout
* Meaningful structure for page sections
